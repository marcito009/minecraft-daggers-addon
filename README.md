# 🗡️ Add-on de Adagas para Minecraft Bedrock 26.44

## Características

✅ **6 tipos de adagas** (Madeira, Pedra, Ferro, Ouro, Diamante, Netherita)  
✅ **Animações de combate** integradas  
✅ **Funcionam na segunda mão (offhand)**  
✅ **Arremessáveis** até 6 blocos de distância  
✅ **Crafting customizado** para cada tipo  
✅ **Efeitos e durabilidade** realistas  
✅ **Cooldown de 15 segundos** entre arremessos  

## Danos das Adagas

| Tipo | Dano | Durabilidade |

| 🪨 Pedra | 3 | 131 |

| 🔥 Netherita | 8 | 2031 |

## Crafting

Todas as adagas usam o mesmo padrão:

```
#
#
|
```

Onde `#` é o material (madeira, pedra, ferro, ouro, diamante ou netherita) e `|` é um bastão.

## Como Usar

1. **Craftear** a adaga na bancada
2. **Colocar** na mão secundária (offhand)
3. **Crouch + Clicar** para arremessar
4. **Esperar 15 segundos** para reutilizar

## Instalação

1. Copie as pastas `behavior_packs/daggers` e `resource_packs/daggers` para:
   - Windows: `%localappdata%/Packages/Microsoft.MinecraftUWP_8wekyb3d8bbwe/LocalState/games/com.mojang/`
   - Ou importe diretamente em seu mundo

2. Ative o add-on nas configurações do mundo

## Recursos

- 6 itens de adaga
- 6 receitas de crafting
- Sistema de arremesso com entidade de projétil
- Cooldown de 15 segundos integrado
- Efeitos de impacto e partículas
